
# Datheon Machine Learning & Data Science Internship

This repository contains my project work for the Datheon Machine Learning & Data Science Internship.

## Tasks

### Task 1: Iris Flower Classification
A machine learning classification project using the Iris dataset, with exploratory data analysis, model training, and performance evaluation.

Folder: `datheon_task1_iris_classification_package`

### Task 2: California Housing Price Prediction
A regression project comparing linear and regularized regression models for housing-price prediction.

Folder: `datheon_task2_california_housing_package`

### Task 3: Customer Churn Classification
A classification project for identifying customers likely to leave a service, using preprocessing, model evaluation, and churn-related metrics.

Folder: `datheon_task3_sentiment_classifier_package`

### Task 4: Sentiment Analysis
A text-classification project using TF-IDF features and machine learning models to classify sentiment.

Folder: `datheon_task4_sentiment_classifier_package`

## Technologies

- Python
- Jupyter Notebook
- pandas and NumPy
- Matplotlib and Seaborn
- scikit-learn
- Machine Learning and Natural Language Processing

## How to Run

1. Clone or download this repository.
2. Open the relevant task folder.
3. Install the dependencies listed in its requirements file.
4. Launch Jupyter Notebook and run the notebook cells.

## Note

Model performance and results should be verified by executing the notebooks in the intended environment.
